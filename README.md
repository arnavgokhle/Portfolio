# Arnav Gokhle — portfolio

React 19 + Vite, `motion`, `lucide-react`, react-router-dom. Plain CSS.

```bash
npm install
npm run dev
```

- Project copy lives in `src/content/projects.js` (one object per project).
- Site-wide links and labels live in `src/content/site.js`.
- Drop `public/hero.mp4` (and optionally `public/hero-poster.jpg`) to enable the
  landing-page background video. Without them the hero is plain white.
